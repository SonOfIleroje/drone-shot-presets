    How to get it into DJI Fly
    1. Make a placeholder: in DJI Fly (drone connected) create a Waypoint flight with 2–3 points anywhere and save it. Give it a name like ORBIT.
    2. Grab its file:
      iPhone: Files app → On My iPhone → DJI Fly → wayline_mission → newest folder → the .kmz. AirDrop it to this Mac.
      Android: Android/data/dji.go.v5/files/waypoint/ → newest folder → .kmz (plug into the Mac and use OpenMTP, Android hides this folder from most apps).
    3. Load it above, plan the shot, press Export. You get a file with the exact same name.
    4. Put it back: replace the original file in the same folder (AirDrop to iPhone → Save to Files → that folder → Replace).
    5. Force-close DJI Fly, reopen it, open your waypoint flight. Check the path on the map looks right.
    6. Take off from ground level near the start of the shot (heights are measured from take-off), press record, press Go. Keep your thumbs near the sticks.

    This file-swap trick is used by Litchi Hub and works on the Air 3/3S, but DJI Fly updates sometimes break it. If the mission loads blank, re-make the placeholder after updating DJI Fly.
